# Google Cloud - CI/CD

En esta sección vamos a empezar a trabajar con Google Cloud, desde instalaciones hasta construcción automática.

Puntualmente veremos:

- gcloud cli
  - Instalaciones
  - Configuraciones
- Registros privados
- Subida de imágenes - Push
- Construcción de imágenes que requieren secretos
- Secret Manager
  - Configuración
  - Permisos

Es una sección que nos ayudará a comprender procesos de construcción automática simples y con secretos como el URL de la base de datos para aplicar migraciones y generar el cliente de prisma.
